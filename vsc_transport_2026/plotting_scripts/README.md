# Plotting Scripts

This folder contains the plotting scripts and data used to generate the figures in manuscript and SI.  
The needed data for plotting is in the folder `data/`, and all the figures and movies are stored in `figures/` folder.

## Contents

- `plotting.py`: Plotting script for all figures and movies.
- `simulate_1d_symmetry_breaking.py`: Standalone model for a one-dimensional polariton spectrum with spatial translational-symmetry breaking.
- `columnplots.py`: Plotting style used by `plotting.py`.
- `data/`: Plotting data.
- `figures/`: Outputted figures and movies.
