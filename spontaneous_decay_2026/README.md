# 2026 Spontaneous Decay

This folder contains the simulation inputs, plotting scripts, and relevant data for the spontaneous decay study using MaxwellLink.

## Contents

- `inputs/`: Input files for the spontaneous decay simulations.
- `plotting/`: Python scripts for plotting and post-processing the results.

**Tip:** [MaxwellLink v0.5.0](https://github.com/TaoELi/MaxwellLink/releases/tag/v0.5.0) was used to perform this research. A newer version of MaxwellLink may not exactly follow the same inputs, which may change in later updates. Please always use [MaxwellLink v0.5.0](https://github.com/TaoELi/MaxwellLink/releases/tag/v0.5.0) to reproduce this research.
